# Hackathon PyTorch UNSCH 2025 Landing Page

Landing page minimalista y de tema oscuro para promocionar la Hackathon PyTorch UNSCH 2025, diseñada con la paleta de colores de PyTorch y lista para desplegarse en GitHub Pages.

## Contenido

- Información principal del evento (fecha, lugar, requisitos).
- Agenda detallada por horarios.
- Organizaciones participantes.
- Llamadas a la acción con enlace al formulario de inscripción.

## Estructura del proyecto

```
├── index.html   # Página principal con estilos embebidos
└── README.md    # Este documento
```

## Personalización

1. Abre `index.html` y ajusta el texto o los enlaces según necesites.
2. Si deseas cambiar los colores, modifica las variables CSS definidas en la sección `<style>`.

## Despliegue en GitHub Pages

1. Crea un repositorio en GitHub y sube `index.html` y `README.md`.
2. Ve a **Settings → Pages**.
3. En **Source**, selecciona la rama (por ejemplo `main`) y la carpeta raíz (`/root`).
4. Guarda los cambios y espera a que GitHub genere la página. La URL tendrá el formato `https://tuusuario.github.io/nombre-del-repo/`.

## Formulario de inscripción

Actualiza el atributo `href` de los botones dentro de `index.html` con la URL de tu formulario si cambia en el futuro.

## Requisitos para participantes

- Conocimientos básicos de Python.
- Disponibilidad para asistir el 29 de noviembre de 2025 en la Escuela de Ingeniería de Sistemas UNSCH.
